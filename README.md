<h2 align="center">03 / FEATURED PROJECT</h2>

<div align="center">

# IntentOS

### INTELLIGENT EXECUTION GATEKEEPER

</div>

IntentOS adds a decision layer between an AI system's intent and its execution. It is designed to make autonomous workflows more controlled, predictable, and accountable.

| Decision | Meaning |
|:--|:--|
| **ACT** | Allow an action when it meets the system's rules. |
| **ASK** | Request clarification when intent or required information is unclear. |
| **REVIEW** | Escalate consequential actions for human approval. |

**Core idea:** useful autonomy should be paired with clear execution boundaries and human oversight.
